SAFIKUL ISLAM — UPDATED PORTFOLIO WEBSITE
=========================================

OPEN THE WEBSITE
1. Extract this ZIP file.
2. Open the Safikul_Islam_Portfolio_Visual folder.
3. Double-click index.html to open it in Chrome or Edge.

EDIT THE WEBSITE
- Open index.html in VS Code to edit text or sections.
- CSS is inside the <style> block near the top of index.html.
- Personal photos are stored in the assets folder. Replace an image while keeping the same filename, or update the corresponding src path in index.html.
- The web page can also be previewed with the standalone HTML file supplied separately; its images are embedded in the file.

NOTES
- Review your contact details before publishing the portfolio online.
- The computer-workspace picture is decorative; the personal-photo gallery uses your uploaded photographs.
- The old skill progress bars are visual placeholders and are not formal test scores.
